# 售后服务与平台政策

## 退换货政策

### 7天无理由退货
- 自签收之日起7天内，商品完好不影响二次销售可无理由退货
- 退回运费由买家承担（平台赠送退运险的可享首重免费）
- 以下商品不支持无理由退货：生鲜食品、已拆封的数码软件、内衣内裤、定制商品

### 质量问题退换
- 签收后30天内出现非人为质量问题，可申请换货或退货
- 需提供商品质量问题照片/视频作为凭证
- 运费由平台承担，上门取件免运费
- 大件商品（冰箱、洗衣机、空调等）由品牌售后上门鉴定

### 各品类特殊退换规则
| 品类 | 无理由退货 | 质量问题换货 | 保修期 |
|------|:----------:|:----------:|:------:|
| 手机数码 | 7天（未激活） | 15天换货 | 1年 |
| 电脑办公 | 7天（未激活） | 15天换货 | 2年 |
| 家用电器 | 7天（未安装） | 30天换货 | 整机1年/主要部件3年 |
| 服装鞋帽 | 7天（吊牌完整） | 30天换货 | 无 |
| 食品生鲜 | 不支持 | 24小时内凭照片退款 | 无 |
| 美妆个护 | 7天（未拆封） | 30天退货 | 无 |

## 退款流程

1. 在"我的订单"中找到对应订单，点击"申请售后"
2. 选择售后类型：退货退款/仅退款/换货
3. 填写退款原因并上传凭证照片
4. 提交后等待商家审核（1-3个工作日）
5. 审核通过后，上门取件/自行寄回
6. 商家收货确认后，退款原路返回

## 退款时效
- **支付宝/微信支付**: 1-3个工作日到账
- **银行卡支付**: 3-7个工作日到账
- **货到付款**: 需提供银行卡号，3-7个工作日到账

## 价格保护政策
- 下单后7天内商品降价，可在"我的订单"中申请价格保护
- 系统自动计算差价，审核通过后退还差额
- 秒杀、闪购、限量抢购商品不参与价格保护
- 每个订单限申请一次价格保护

## 发票管理
- 下单时可选择开具电子发票或纸质发票
- 电子发票在确认收货后自动发送至注册邮箱
- 纸质发票随包裹寄出或单独邮寄（包邮）
- 发票类型：增值税普通发票、增值税专用发票（需提供开票资料）
- 发票内容：默认按商品明细开具，不支持修改发票内容

- 积分获取方式：购物、签到、评价、参与活动
